# Tactic Tiles

A puzzle game where you match a picture by writing short proofs. Each line is one move. Proofs can be exported to Lean 4.

The app lives in [`tactic-tiles/`](tactic-tiles). See its [README](tactic-tiles/README.md) for features, the proof language and how to run it.

```sh
cd tactic-tiles
npm install
npm run dev
```
